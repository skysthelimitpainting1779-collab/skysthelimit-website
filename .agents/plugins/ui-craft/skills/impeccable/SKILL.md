# Impeccable Post-Implementation Review Skill

## Purpose
Post-implementation critique applied to UI deliverables to ensure pristine execution before blind verification.

## Review Checklist
1. **Spacing & Alignment**: Strict 4px/8px grid cadence, no rogue padding/margin overrides.
2. **Typography**: Correct line-height, contrast ratios, and font weight hierarchy.
3. **Accessibility**: ARIA attributes, keyboard focus states, color contrast WCAG AA compliant.
4. **Motion Quality**: Snappy spring transitions without layout jank.
