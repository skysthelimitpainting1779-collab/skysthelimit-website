# Taste Creative Direction Skill

## Purpose
Prevents generic AI UI clichés and infuses artisanal craftsmanship, crisp typography, and purposeful motion.

## Cliché Checks
- NO purple/violet accents on dark mode.
- NO glow borders or unnecessary gradient headlines.
- NO icon-stuffed bento boxes.
- Ensure strict typography letter-spacing / tracking and balanced whitespace.
