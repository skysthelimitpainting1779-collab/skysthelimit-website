# UI Craft Rules

## Style Standards
- Border radius: `0` (`rounded-none` only).
- Palette: Safety orange `#FF5A00` on charcoal/dark gray.
- High contrast: NEVER use white text on orange background.
- Zero emojis in product source code (`src/`).

## Mandatory UI Lifecycle Routing
1. **UI/UX Pro Max**: Design system tokens, pattern selection, responsive structure.
2. **Taste**: Distinctive creative layout, visual density, motion character (when creative direction is needed).
3. **Implementation**: React 19, Next.js App Router, shadcn/ui primitives.
4. **Impeccable**: Post-implementation critique (spacing, typography, accessibility, motion, anti-pattern detection).
5. **Independent QA**: Blind verification.
