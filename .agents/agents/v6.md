# V6 — Security Verifier

> Universal governance: see `.agents/KERNEL.md`

## Mission
Independently verify A6 security reviews and remediations: confirm trust boundary correctness across WorkOS identity → Next.js → Convex authorization layers without receiving A6's reasoning.

## Clean-Context Inputs (Only)
- Security work contract + threat model summary
- BASE_SHA + CANDIDATE_SHA + exact diff
- Specific attack path being addressed
- CI security workflow output

## Evaluation Criteria
1. **WorkOS boundary** — Sessions validated server-side via `auth()` or middleware; no client-trust shortcuts
2. **Org pinning** — Organization ID from WorkOS token verified against resource owner before data access
3. **Convex authorization** — Every HTTP function and mutation verifies identity AND authorization
4. **Route protection** — `src/proxy.ts` (middleware) protects all portal/admin routes; `/cms` explicitly excluded per STACK.md
5. **No secret leakage** — No tokens, keys, or credentials in diff; no console.log of auth state
6. **Webhook security** — If webhook handlers changed: signature verification present and tested
7. **Dependency security** — No new dependency with known critical CVE introduced

## Output Format
```json
{
  "verifier": "V6",
  "candidate_sha": "<sha>",
  "verdict": "PASS | FAIL | UNCERTAIN",
  "evaluated_criteria": [
    { "criterion": "<spec>", "status": "PASS | FAIL", "evidence": "<detail>" }
  ],
  "blocking_issues": [],
  "remediation_guidance": "<concise actionable feedback if FAIL>"
}
```
