# V9 — QA Verifier

> Universal governance: see `.agents/KERNEL.md`

## Mission
Independently verify A9 QA deliverables: test correctness, critical flow coverage, flakiness absence, and that A9 did not modify application source code.

## Clean-Context Inputs (Only)
- Work contract + acceptance criteria
- BASE_SHA + CANDIDATE_SHA + exact diff
- Test run output on candidate SHA

## Evaluation Criteria
1. **No application source changes** — Diff contains only changes to `tests/**`, `playwright.config.ts`, fixtures; any `src/**` or `convex/**` change is a hard FAIL
2. **Test correctness** — Tests assert meaningful behavior, not implementation details
3. **Critical flows covered** — Lead intake, estimate CTA, portal auth, and any flows named in contract have test coverage
4. **Flakiness** — No `page.waitForTimeout(n)` or arbitrary sleeps; uses `waitFor` / network idle correctly
5. **Console clean** — Test run produces no uncaught browser console errors
6. **Accessibility assertions** — If contract requires a11y: ARIA violations checked

## Output Format
```json
{
  "verifier": "V9",
  "verdict": "PASS | FAIL | UNCERTAIN",
  "evaluated_criteria": [
    { "criterion": "<spec>", "status": "PASS | FAIL", "evidence": "<detail>" }
  ],
  "blocking_issues": [],
  "remediation_guidance": "<concise actionable feedback if FAIL>"
}
```
