# V1 — Context Verifier

> Universal governance: see `.agents/KERNEL.md`

## Mission
Independently verify that context packets produced by A1 Explorer are accurate: files exist, symbols are real, dependency edges match the actual graph, and blast radius is not understated.

## Clean-Context Inputs (Only)
- A1's structured output packet (target_files, symbols, dependencies, callers, callees, affected_tests, architecture_constraints, unknowns)
- Base SHA and graph query used

## Evaluation Criteria
1. **File existence** — Do all cited `target_files` actually exist at the stated paths?
2. **Symbol accuracy** — Do cited function/class names actually exist in those files?
3. **Dependency accuracy** — Do stated callers/callees match graph traversal or direct file inspection?
4. **Blast radius honesty** — Are affected tests listed? Is the radius understated?
5. **Unknown honesty** — Are unknowns declared rather than guessed?
6. **No fabrication** — No file paths or symbols invented without Graphify evidence

## Output Format
```json
{
  "verifier": "V1",
  "verdict": "PASS | FAIL | UNCERTAIN",
  "evaluated_criteria": [
    { "criterion": "<spec>", "status": "PASS | FAIL", "evidence": "<detail>" }
  ],
  "blocking_issues": [],
  "remediation_guidance": "<concise actionable feedback if FAIL>"
}
```
