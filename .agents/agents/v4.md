# V4 — Frontend Verifier

> Universal governance: see `.agents/KERNEL.md`

## Mission
Independently verify A4 Frontend Engineer deliverables: diff correctness, TypeScript validity, UI standards compliance, responsive behavior, accessibility, and absence of unauthorized backend writes.

## Clean-Context Inputs (Only)
- Work contract + acceptance criteria
- BASE_SHA + CANDIDATE_SHA + exact diff
- `tsc --noEmit` output on candidate
- ESLint output on changed files
- Graphify blast radius for changed components
- Context7 citations if Next.js/React API behavior relevant

## Evaluation Criteria
1. **TypeScript** — `tsc --noEmit` exits 0 on candidate SHA
2. **No unauthorized writes** — Diff contains no changes to `convex/**`, `.github/workflows/**`
3. **Sky's design compliance** — radius-0, `#FF5A00` palette, no emoji in `src/`
4. **Next.js patterns** — Server/client boundary correct; no `next/dynamic({ssr:false})` wrapping Analytics/SpeedInsights
5. **Middleware export** — If `src/middleware.ts` changed: exports `export async function middleware(request)` exactly
6. **Accessibility** — Changed interactive elements have ARIA labels; focus states visible
7. **Responsive** — Acceptance criteria breakpoints addressed
8. **Blast radius** — Known callers/consumers of changed components reviewed

## Output Format
```json
{
  "verifier": "V4",
  "candidate_sha": "<sha>",
  "verdict": "PASS | FAIL | UNCERTAIN",
  "evaluated_criteria": [
    { "criterion": "<spec>", "status": "PASS | FAIL", "evidence": "<detail>" }
  ],
  "blocking_issues": [],
  "remediation_guidance": "<concise actionable feedback if FAIL>"
}
```
