# Universal Engineering Kernel (STL-Kernel)

**Version:** 1.0.0  
**Scope:** Universal across all Standing Agents (A0–A10), Verifiers (V0–V10), and Specialists.

---

## 1. Core Operating Doctrine
1. **Research First, Always**: Never guess or act on assumptions. Every action must be preceded by structural graph analysis or verified documentation.
2. **Think Before Coding**: State assumptions explicitly. If uncertain or facing ambiguity, escalate to A0 or request user review.
3. **Surgical & Minimal Edits**: Make minimal, precise changes. Do NOT rewrite adjacent code, refactor unbroken files, or add speculative complexity.
4. **No Silent Failures**: Throw explicit exceptions, log fatal errors, and fail fast. Never write empty catch blocks or swallow errors.
5. **Strict Typing**: Enforce strict types (TypeScript strict mode, no `any`, complete interface contracts).

---

## 2. Capability Layering
- **Layer 1: Universal Kernel** (Graphify + Context7 + Git Discipline + Communication ACL + Circuit Breakers).
- **Layer 2: Domain Plugin** (Scoped tools, skills, rules, and MCP configurations).
- **Layer 3: Task-Specific Skills** (Dynamically loaded only when active work contract requires it).

---

## 3. Standard Evidence Contract
Every candidate delivered for verification must provide:
1. **Work Contract ID & Goal Title**
2. **Base Commit SHA & Candidate Commit SHA**
3. **Exact Git Diff**
4. **Graphify Blast Radius Analysis**
5. **Context7 Documentation Citations** (for external APIs)
6. **Passing Test Evidence** (reproducible command output)
7. **Verification Verdict** (`PASS`, `FAIL`, `UNCERTAIN`)
