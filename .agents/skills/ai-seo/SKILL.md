# AI SEO

Use current public crawler and search documentation; do not rely on remembered bot names or policies.

1. Verify that robots, authentication, caching, and response status permit only the intended public content.
2. Align visible copy, headings, metadata, structured data, canonicals, and stable entity identifiers.
3. Make claims directly supportable by public provenance; do not generate testimonials, credentials, locations, or metrics.
4. Keep customer data, draft content, operator surfaces, and opaque internal identifiers out of public retrieval.
5. Test rendered HTML without client execution, canonical consistency, structured-data validity, and crawler-denied private routes.

Report evidence by URL and source file. Treat AI visibility as secondary to accuracy, privacy, accessibility, and conventional technical SEO.
