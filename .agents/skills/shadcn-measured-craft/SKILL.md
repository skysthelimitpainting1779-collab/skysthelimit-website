# shadcn Measured Craft

Load the official `shadcn` skill before editing components.

Use source-owned shadcn components, semantic tokens, complete component composition, accessible labels/titles, and existing primitives before custom markup. Preserve the orange/charcoal brand without hardcoded parallel color systems. Use semantic geometry rather than global radius-zero dogma. Verify keyboard, focus, reduced motion, mobile layouts, and visual regression.
