# User Flow Map

## Homeowner

```text
Landing page
→ understand fit
→ inspect preparation/proof
→ planning range
→ guided estimate
→ durable lead saved
→ schedule
→ estimate
→ proposal
→ agreement
→ deposit
→ project portal
→ closeout
→ honest review / referral
```

## Commercial property

```text
Commercial landing
→ property/use constraints
→ capability and project proof
→ scope review
→ appointment
→ estimate/proposal
→ approval/payment
→ project execution and documents
```

## Public/facility buyer

```text
Public-sector landing
→ qualification facts
→ capabilities/documents
→ opportunity or scope conversation
→ operator qualification
→ bid/proposal workflow
→ project when awarded
```

## Customer portal

```text
Invite/sign-in
→ overview identifies one next action
→ review document or status
→ approve/sign/pay/upload/message
→ confirmation and updated timeline
```

## Operator

```text
New event
→ prioritized dashboard/task
→ open canonical record
→ complete one governed action
→ domain event and audit fact
→ durable external effect
→ reconciliation and next task
```
